# P1 — Parking Lot

| | |
|---|---|
| **Topic** | Closed hashing (linear probing) |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A parking lot has `M` numbered spaces and uses **closed hashing with linear probing**.
Each arriving car is identified by an integer key. The home space for a key is

```
h(k) = ((k mod M) + M) mod M
```

If the home space is taken, the car checks `h(k) + 1`, `h(k) + 2`, ... (wrapping around
at `M`) until it finds an empty space. Before inserting, the search must also detect a
car that is already parked: if the same key is found before an empty space, the car is
a duplicate.

For every arriving car, report what happened:

- `PARKED slot` — the car was placed in `slot`.
- `ALREADY slot` — the same key is already parked in `slot`.
- `FULL` — all `M` spaces were examined without finding the key or an empty space.

Count a **probe** for every space examined, including probes made by duplicate and
failed attempts.

After all cars are processed, print the final table and the total number of probes.

## Input Format

- The first line contains two integers, `M` and `N`.
- The next `N` integers are the car keys. They may be spread across one or more lines.

## Output Format

Print one status line per arriving car. Then print:

```
table:
```

followed by exactly `M` lines:

- `i: key` if space `i` is occupied,
- `i: empty` if space `i` is free.

Finally print:

```
probes: total
```

where `total` is the total number of probes over all cars.

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ N ≤ 10000`
- `-10^9 ≤ key ≤ 10^9`

## Sample Input 1

```text
7 5
10 3 17 24 31
```

## Sample Output 1

```text
PARKED 3
PARKED 4
PARKED 5
PARKED 6
PARKED 0
table:
0: 31
1: empty
2: empty
3: 10
4: 3
5: 17
6: 24
probes: 15
```

## Explanation

All five keys have home space `3` because they are congruent to `3 mod 7`.

| Key | Spaces examined | Result | Probes |
|-----|-----------------|--------|--------|
| 10 | 3 | parked at 3 | 1 |
| 3 | 3, 4 | parked at 4 | 2 |
| 17 | 3, 4, 5 | parked at 5 | 3 |
| 24 | 3, 4, 5, 6 | parked at 6 | 4 |
| 31 | 3, 4, 5, 6, 0 | parked at 0 | 5 |

The total is `1 + 2 + 3 + 4 + 5 = 15`.

## Hints

1. Keep a separate `used` array so you can tell an occupied space from a free one even
   when the stored key could be any integer.
2. Normalize negative keys before taking the remainder.
3. Stop a duplicate search as soon as you see an empty space — the key cannot appear
   after a gap in linear probing.
4. Count the probe as soon as you examine a space, even if it is occupied.
5. Use a `long long` for the total probe count.
