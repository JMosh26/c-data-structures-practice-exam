# P2 — Quadratic Quest

| | |
|---|---|
| **Topic** | Closed hashing (quadratic probing) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A table with `M` slots uses **quadratic probing**:

```
h(k)  = ((k mod M) + M) mod M
slot  = (h(k) + i * i) mod M    for i = 0, 1, ..., M - 1
```

Insert `N` keys in order:

1. If the key is already in the table, ignore it.
2. Otherwise try the probe sequence above. Place the key in the first empty slot.
3. If all `M` probes fail, the key is rejected. Print `FAILED <key>`.

Count probes globally: every slot the algorithm examines adds `1`, including the slot
where the key is placed and every occupied slot that forces another attempt. A rejected
key contributes exactly `M` probes. Ignoring a duplicate contributes `0` probes.

After all insertions, print the total probe count and then the table.

## Input Format

```
M N
k1 k2 ... kN
```

## Output Format

1. One `FAILED <key>` line for each rejected key, in insertion order.
2. One line: `probes: <total>`
3. `M` table lines:
   - Occupied: `i: key`
   - Empty: `i: (empty)`

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ N ≤ 2M`
- `-10^9 ≤ key ≤ 10^9`

## Sample Input 1

```text
7 5
0 7 14 21 28
```

## Sample Output 1

```text
FAILED 28
probes: 17
0: 0
1: 7
2: 21
3: (empty)
4: 14
5: (empty)
6: (empty)
```

## Explanation

All five keys hash to slot `0`. The quadratic sequence modulo `7` is:

```
i:     0  1  2  3  4  5  6
i*i:   0  1  4  2  2  4  1
```

| Key | Slots examined | Probes | Result |
|-----|----------------|--------|--------|
| 0 | 0 | 1 | slot 0 |
| 7 | 0, 1 | 2 | slot 1 |
| 14 | 0, 1, 4 | 3 | slot 4 |
| 21 | 0, 1, 4, 2 | 4 | slot 2 |
| 28 | 0, 1, 4, 2, 2, 4, 1 | 7 | rejected |

Total probes: `1 + 2 + 3 + 4 + 7 = 17`.

Notice that quadratic probing does **not** always visit every slot. With `M = 7` and
this key, slots `3`, `5`, and `6` are never examined, so the key fails even though the
table is not full.

## Hints

1. `i * i` fits easily in `int` for `M ≤ 1000`, but `(h + i*i) % M` is the safe form.
2. Track duplicates by scanning the occupied slots before probing.
3. Do not reset the probe counter between insertions.
