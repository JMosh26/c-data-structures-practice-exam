# P1 — Min-Heap Machine

| | |
|---|---|
| **Topic** | Priority queue (binary min-heap) |
| **Difficulty** | Medium |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

Implement a **min-heap** of integers and process `Q` commands. The smallest value has
the highest priority.

| Command | Meaning |
|---------|---------|
| `INSERT x` | Insert `x` into the heap |
| `EXTRACT` | Remove and print the minimum; print `EMPTY` if the heap is empty |
| `PEEK` | Print the minimum without removing it; print `EMPTY` if empty |
| `SIZE` | Print the number of elements |
| `PRINT` | Print the heap array in level order, separated by single spaces; print `EMPTY` if empty |

`PRINT` shows the internal array, **not** the sorted order. For an array-based heap,
index `0` is the root, and the children of index `i` are `2i + 1` and `2i + 2`.

## Input Format

- The first line contains `Q`.
- The next `Q` lines each contain one command.

## Output Format

Print output only for `EXTRACT`, `PEEK`, `SIZE`, and `PRINT`, one result per line.

## Constraints

- `1 ≤ Q ≤ 1000`
- `-10^9 ≤ x ≤ 10^9`

## Sample Input 1

```text
9
INSERT 5
INSERT 3
INSERT 8
PEEK
EXTRACT
SIZE
INSERT 1
EXTRACT
PRINT
```

## Sample Output 1

```text
3
3
2
1
5 8
```

## Explanation

| Step | Heap array (level order) | Output |
|------|--------------------------|--------|
| `INSERT 5` | `5` | — |
| `INSERT 3` | `3 5` | — |
| `INSERT 8` | `3 5 8` | — |
| `PEEK` | `3 5 8` | `3` |
| `EXTRACT` | `5 8` | `3` |
| `SIZE` | `5 8` | `2` |
| `INSERT 1` | `1 8 5` | — |
| `EXTRACT` | `5 8` | `1` |
| `PRINT` | `5 8` | `5 8` |

## Hints

1. Store the heap in a fixed array of at least `1001` integers.
2. `INSERT`: append at the end, then bubble up while the parent is larger.
3. `EXTRACT`: save the root, move the last element to the root, shrink the heap, then
   sift down by swapping with the smaller child.
4. `PRINT` has no trailing space.
