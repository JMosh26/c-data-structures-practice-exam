# P1 — Roller Coaster

| | |
|---|---|
| **Topic** | Priority queue (binary min-heap) |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A roller coaster keeps its waiting riders in a **binary min-heap** keyed by ticket
number, so the smallest ticket always boards next. Duplicate ticket numbers are allowed.

Process `Q` commands:

| Command | Meaning |
|---------|---------|
| `ADD v` | Insert ticket `v`. |
| `RIDE` | Remove and print the smallest ticket. |
| `TAKE k` | Remove and print the `k` smallest tickets on one line. |
| `PEEK` | Print the smallest ticket without removing it. |
| `SIZE` | Print how many tickets are waiting. |
| `DUMP` | Print the heap's internal array in level order. |

Details:

- `RIDE` prints `RIDE v`, or `EMPTY` if the heap is empty.
- `PEEK` prints the value, or `EMPTY` if the heap is empty.
- `TAKE k` prints the removed values separated by single spaces. If the heap is empty or
  `k ≤ 0`, print `EMPTY`. If `k` is larger than the heap size, take every waiting rider.
- `DUMP` prints the internal array from index `0` to `size - 1`, separated by single
  spaces, or `EMPTY` when the heap is empty. This is **not** sorted order; it is the
  heap's level-order storage.

## Input Format

- The first line contains one integer, `Q`.
- The next `Q` lines each contain one command.
- For `ADD`, the ticket value is an integer. For `TAKE`, `k` is a non-negative integer.

## Output Format

Print output only for `RIDE`, `TAKE`, `PEEK`, `SIZE`, and `DUMP`, exactly as described.

## Constraints

- `0 ≤ Q ≤ 1000`
- `-10^9 ≤ v ≤ 10^9`
- `0 ≤ k ≤ 10^9`

## Sample Input 1

```text
12
ADD 5
ADD 3
ADD 8
ADD 1
PEEK
RIDE
TAKE 2
SIZE
DUMP
ADD 2
ADD 2
TAKE 5
```

## Sample Output 1

```text
1
RIDE 1
3 5
1
8
2 2 8
```

## Explanation

After `ADD 5`, `ADD 3`, `ADD 8`, `ADD 1`, the smallest ticket is `1`.

- `PEEK` prints `1`.
- `RIDE` removes `1` and prints `RIDE 1`.
- `TAKE 2` removes the next two smallest tickets, `3` and `5`.
- `SIZE` is `1`; `DUMP` shows the single remaining value `8`.
- Two more `ADD 2` commands create duplicates. `TAKE 5` removes `2`, `2`, and `8`, which
  is all remaining tickets.

## Hints

1. Store the heap in a 0-based array.
2. For index `i`, the parent is `(i - 1) / 2` and the children are `2*i + 1` and
   `2*i + 2`.
3. On insert, append the value and bubble it up while it is smaller than its parent.
4. On removal, save the root, move the last element to the root, decrease the size, and
   sift the new root down.
5. `DUMP` prints the array as stored, not the values in removal order.
6. `TAKE` should call the same removal routine repeatedly.
