# P3 — Stream Merger

| | |
|---|---|
| **Topic** | Priority queue (k-way merge) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

You are given `K` streams of integers. Each stream is **non-increasing**: every value is
less than or equal to the value before it. Merge all streams into one non-increasing
stream using a priority queue.

The merge must be **stable** with respect to stream order: when two streams offer the
same value, take the value from the **smaller stream index** first. Since each stream is
already non-increasing, this rule completely determines the output order.

If every stream is empty, print `EMPTY`.

## Input Format

- The first line contains one integer, `K`.
- The next `K` lines describe the streams in order:
  - the first integer is the stream length `L`,
  - followed by `L` integers, the stream's values.

A length of `0` means the stream is empty.

## Output Format

Print the merged values on one line, separated by single spaces. Print `EMPTY` if there
are no values at all.

## Constraints

- `1 ≤ K ≤ 1000`
- `0 ≤ L ≤ 1000` for each stream
- The total number of values is at most `1,000,000`.
- `-10^9 ≤ value ≤ 10^9`

## Sample Input 1

```text
3
3 9 6 3
2 8 5
4 7 4 2 1
```

## Sample Output 1

```text
9 8 7 6 5 4 3 2 1
```

## Explanation

The initial heads are `9` (stream 0), `8` (stream 1), and `7` (stream 2). The heap always
returns the largest head. After taking `9` from stream 0, its next value `6` enters the
heap, and so on. The merged output is

```
9 8 7 6 5 4 3 2 1
```

## Sample Input 2

```text
4
2 10 1
0
3 10 10 9
1 8
```

## Sample Output 2

```text
10 10 10 9 8 1
```

## Explanation 2

The three `10`s come from stream 0, then stream 2 (twice), in stream-index order. The
rest follow normally.

## Hints

1. Each heap item needs three fields: `value`, `list` (stream index), and `index`
   (position inside that stream).
2. `comes_before(a, b)` should be true when `a.value > b.value`, or when the values are
   equal and `a.list < b.list`.
3. Push the first value of every non-empty stream into the heap.
4. After popping an item, push the next value from the same stream, if any.
5. Separate the output values with spaces without printing a trailing space.
6. Remember to free every stream buffer and the heap.
