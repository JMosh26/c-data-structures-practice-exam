# P3 — Merge the Streams

| | |
|---|---|
| **Topic** | Priority queue (heap of list heads) |
| **Difficulty** | Hard |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

You are given `K` lists of integers. Each list is already sorted in non-decreasing
order. Merge all lists into one sorted sequence using a **min-heap** of the current head
of each list.

Do not sort all values at once. The intended solution keeps one heap node per list and
repeatedly extracts the smallest value, then pushes the next value from that same list.

## Input Format

```
K
n1 a1 a2 ... an1
n2 b1 b2 ... bn2
...
nK ...
```

- The first line contains `K`.
- Each of the next `K` lines starts with the list length `n`, followed by `n` integers
  in non-decreasing order.

## Output Format

Print the merged sequence on one line, with single spaces between values and no
trailing space.

## Constraints

- `1 ≤ K ≤ 100`
- `1 ≤ n ≤ 100`
- Total number of values ≤ 10000
- `-10^9 ≤ value ≤ 10^9`

## Sample Input 1

```text
2
3 1 4 7
3 2 5 6
```

## Sample Output 1

```text
1 2 4 5 6 7
```

## Explanation

The heap starts with the heads `1` and `2`:

| Extract | Push next from its list | Heap after |
|---------|-------------------------|------------|
| 1 | 4 | 2, 4 |
| 2 | 5 | 4, 5 |
| 4 | 7 | 5, 7 |
| 5 | 6 | 6, 7 |
| 6 | — | 7 |
| 7 | — | empty |

## Hints

1. Each heap node needs `value`, the list it came from, and the index inside that list.
2. Read all lists into dynamically allocated arrays, or into one flat array with a
   start index and length per list.
3. Push the first element of every non-empty list before the merge loop.
4. After extracting a node, push the next element of the same list if one exists.
5. Duplicate values are allowed; their relative order does not matter because the
   output is just values.
