# P2 — ER Triage

| | |
|---|---|
| **Topic** | Priority queue (max-heap with a custom comparator) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

An emergency room uses a priority queue of patients. A patient has a name and a
severity score (larger means more urgent).

- Higher severity is treated first.
- If two patients have the same severity, the one who **arrived earlier** is treated
  first (FIFO).

Process `Q` commands:

| Command | Meaning |
|---------|---------|
| `ARRIVE name severity` | Add a patient to the queue |
| `TREAT` | Remove the highest-priority patient and print `TREATING <name> <severity>`; print `NO PATIENTS` if the queue is empty |
| `NEXT` | Print `<name> <severity>` of the highest-priority patient without removing them; print `NO PATIENTS` if empty |
| `COUNT` | Print the number of waiting patients |

## Input Format

- The first line contains `Q`.
- The next `Q` lines each contain one command.

Patient names contain no spaces and are at most 31 characters long.

## Output Format

Print output only for `TREAT`, `NEXT`, and `COUNT`, one result per line, using the
formats above.

## Constraints

- `1 ≤ Q ≤ 1000`
- `1 ≤ severity ≤ 10^9`
- `1 ≤ length of name ≤ 31`

## Sample Input 1

```text
8
ARRIVE Ana 5
ARRIVE Ben 9
ARRIVE Cid 5
NEXT
TREAT
TREAT
TREAT
COUNT
```

## Sample Output 1

```text
Ben 9
TREATING Ben 9
TREATING Ana 5
TREATING Cid 5
0
```

## Explanation

- `Ben` has severity `9`, the highest, so `NEXT` prints him.
- `TREAT` removes `Ben`.
- `Ana` and `Cid` both have severity `5`. `Ana` arrived first, so she is treated first.
- After the last `TREAT`, nobody is waiting, so `COUNT` prints `0`.

## Hints

1. Store `name`, `severity`, and an `arrival` counter in a `struct`.
2. Write a comparison function:
   `a` outranks `b` if `a.severity > b.severity`, or if the severities are equal and
   `a.arrival < b.arrival`.
3. Use that comparison in both bubble-up and sift-down. Do not compare only severities.
4. Increment the arrival counter once per `ARRIVE`.
5. `strcmp` is not needed for priority, but include `<string.h>` if you use it.
