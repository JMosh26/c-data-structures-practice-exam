# P2 — Air Traffic

| | |
|---|---|
| **Topic** | Priority queue (binary heap with a custom comparator) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

An airport tower keeps incoming flights in a **binary max-heap** ordered by a custom
three-key comparator. Each flight has a name, an emergency level, and a scheduled time.
The flight with the **highest priority** lands first, where priority is:

1. **higher emergency level** first,
2. then **earlier scheduled time** (smaller number) first,
3. then **lexicographically smaller flight name** first.

Process `Q` commands:

| Command | Meaning |
|---------|---------|
| `ADD name emergency time` | Add a flight. |
| `LAND` | Remove and print the highest-priority flight. |
| `NEXT` | Print the highest-priority flight without removing it. |
| `COUNT` | Print how many flights are waiting. |

Output formats:

- `LAND` prints `LANDING name emergency time`, or `NONE` if there are no flights.
- `NEXT` prints `name emergency time`, or `NONE` if there are no flights.
- `COUNT` prints one integer.

## Input Format

- The first line contains one integer, `Q`.
- The next `Q` lines each contain one command.
- For `ADD`, `name` has no spaces, followed by the integer `emergency` and the integer
  `time`.

## Output Format

Print output only for `LAND`, `NEXT`, and `COUNT`, exactly as described.

## Constraints

- `0 ≤ Q ≤ 1000`
- `1 ≤ length(name) ≤ 15`
- `0 ≤ emergency ≤ 10^9`
- `0 ≤ time ≤ 10^9`

## Sample Input 1

```text
12
ADD Alpha 3 10
ADD Bravo 5 20
ADD Charlie 5 10
ADD Delta 3 5
NEXT
LAND
LAND
COUNT
ADD Echo 5 10
NEXT
LAND
COUNT
```

## Sample Output 1

```text
Charlie 5 10
LANDING Charlie 5 10
LANDING Bravo 5 20
2
Echo 5 10
LANDING Echo 5 10
2
```

## Explanation

- `Bravo` and `Charlie` both have emergency `5`, but `Charlie` has the earlier time
  (`10` before `20`), so `Charlie` is first.
- After `Charlie` lands, `Bravo` (emergency `5`) is ahead of `Alpha` and `Delta`
  (emergency `3`).
- `COUNT` reports the two remaining flights.
- `Echo` also has emergency `5` and time `10`, so it becomes the next flight.

In sample test 3, three flights have the same emergency and time, so the name breaks the
tie in ascending order.

## Hints

1. Write `higher_priority(a, b)` that returns true when `a` must land before `b`.
2. Compare emergency levels first, then times, then use `strcmp` on the names.
3. On insert, bubble up while the new flight has higher priority than its parent.
4. On removal, sift down by choosing the child with the highest priority.
5. Be consistent: use the same comparator for bubbling up and sifting down.
6. `COUNT` is just the current heap size.
