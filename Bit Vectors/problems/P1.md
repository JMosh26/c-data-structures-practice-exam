# P1 — Light Panel

| | |
|---|---|
| **Topic** | Bit vectors (bitwise operations) |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A control panel has 32 lights numbered `0` (least significant bit) through `31` (most
significant bit). All lights start off. A 32-bit unsigned integer stores the panel: bit
`i` is `1` when light `i` is on.

Process `Q` commands:

| Command | Meaning |
|---------|---------|
| `SET a b` | Turn on every light from `a` through `b`, inclusive. |
| `CLEAR a b` | Turn off every light from `a` through `b`, inclusive. |
| `FLIP a b` | Toggle every light from `a` through `b`, inclusive. |
| `GET p` | Print the state of light `p`. |
| `COUNT` | Print how many lights are on. |
| `PRINT` | Print the whole panel. |

`SET`, `CLEAR`, and `FLIP` print nothing.

## Input Format

- The first line contains one integer, `Q`.
- The next `Q` lines each contain one command.
- For `SET`, `CLEAR`, and `FLIP`, `0 ≤ a ≤ b ≤ 31`.
- For `GET`, `0 ≤ p ≤ 31`.

## Output Format

- `GET p` prints `bit p = v`, where `v` is `0` or `1`.
- `COUNT` prints one integer.
- `PRINT` prints exactly 32 characters, from bit `31` down to bit `0`, followed by a
  newline. Bit `31` is the leftmost character.

## Constraints

- `0 ≤ Q ≤ 1000`

## Sample Input 1

```text
10
SET 0 3
GET 2
COUNT
FLIP 1 4
PRINT
CLEAR 0 31
COUNT
GET 5
SET 31 31
PRINT
```

## Sample Output 1

```text
bit 2 = 1
4
00000000000000000000000000010001
0
bit 5 = 0
10000000000000000000000000000000
```

## Explanation

1. `SET 0 3` turns on bits `0, 1, 2, 3`, so `COUNT` is `4`.
2. `FLIP 1 4` toggles bits `1` through `4`. Bits `1, 2, 3` turn off and bit `4` turns
   on, leaving only bits `0` and `4` set. That is `000...00010001`.
3. `CLEAR 0 31` turns everything off.
4. `SET 31 31` turns on only the most significant bit, printed as `1` followed by 31
   zeros.

## Hints

1. Build a range mask with `((1u << width) - 1) << a`, where `width = b - a + 1`.
2. When `width` is 32, shifting by 32 is undefined behavior. Return `UINT32_MAX` for the
   full range instead.
3. `SET` uses `|=`, `CLEAR` uses `&= ~mask`, and `FLIP` uses `^=`.
4. Kernighan's trick counts set bits: `bits &= bits - 1` removes one set bit per
   iteration.
5. `PRINT` starts at bit 31 and works down to bit 0.
