# P1 — Bit Vector Playground

| | |
|---|---|
| **Topic** | Bit vectors / bitwise operations |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A bit vector is a compact array of bits. Implement a **64-bit vector**, initially all
zero, and process `Q` commands. Bit `0` is the least significant bit.

| Command | Meaning |
|---------|---------|
| `SET i` | Set bit `i` to `1` |
| `CLEAR i` | Set bit `i` to `0` |
| `FLIP i` | Toggle bit `i` |
| `GET i` | Print `bit i = v`, where `v` is `0` or `1` |
| `COUNT` | Print the number of bits that are `1` |
| `PRINT` | Print all 64 bits, from bit `63` down to bit `0`, as one line |

## Input Format

- The first line contains `Q`.
- The next `Q` lines each contain one command in the format shown above.

## Output Format

Print output only for `GET`, `COUNT`, and `PRINT` commands, one result per line.

- `GET`: `bit <i> = <v>`
- `COUNT`: the number of set bits
- `PRINT`: exactly 64 characters (`0` or `1`), most significant bit first

## Constraints

- `1 ≤ Q ≤ 10000`
- `0 ≤ i < 64`

## Sample Input 1

```text
9
SET 0
SET 63
SET 5
GET 5
COUNT
CLEAR 5
COUNT
FLIP 5
PRINT
```

## Sample Output 1

```text
bit 5 = 1
3
2
1000000000000000000000000000000000000000000000000000000000100001
```

## Explanation

| Step | Set bits | Output |
|------|----------|--------|
| `SET 0`, `SET 63`, `SET 5` | 0, 5, 63 | — |
| `GET 5` | 0, 5, 63 | `bit 5 = 1` |
| `COUNT` | 0, 5, 63 | `3` |
| `CLEAR 5` | 0, 63 | — |
| `COUNT` | 0, 63 | `2` |
| `FLIP 5` | 0, 5, 63 | — |
| `PRINT` | 0, 5, 63 | 64-bit string |

The printed string has `1` at the positions for bits 63, 5, and 0 (left to right).

## Hints

1. A single `uint64_t` (or `unsigned long long`) is enough.
2. Use `1ULL << i` to build a mask. The `ULL` suffix matters for bit 63.
3. Set: `bits |= mask`; clear: `bits &= ~mask`; flip: `bits ^= mask`.
4. For `PRINT`, loop from `63` down to `0` and test `(bits >> i) & 1ULL`.
5. `__builtin_popcountll(bits)` counts set bits on GCC. A manual loop also works.
