# P3 — Bitset Algebra

| | |
|---|---|
| **Topic** | Bit vectors / set operations |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

Two binary strings `A` and `B` of the same length `L` represent two bit vectors. The
leftmost character is the most significant bit.

Compute the bitwise **AND**, **OR**, and **XOR** of the two vectors, and count the set
bits in each input. Every result must keep the same width `L`, including leading zeros.

## Input Format

One line with two binary strings separated by a space:

```
A B
```

## Output Format

Exactly five lines:

```
AND: <L-bit result>
OR: <L-bit result>
XOR: <L-bit result>
A ones: <count>
B ones: <count>
```

Each result string must be exactly `L` characters long.

## Constraints

- `1 ≤ L ≤ 64`
- `A` and `B` contain only `0` and `1`
- `A` and `B` have the same length

## Sample Input 1

```text
1010 1100
```

## Sample Output 1

```text
AND: 1000
OR: 1110
XOR: 0110
A ones: 2
B ones: 2
```

## Explanation

```
A = 1010
B = 1100
---------
A AND B = 1000
A OR  B = 1110
A XOR B = 0110
```

`A` has two `1` bits and `B` has two `1` bits.

## Hints

1. Convert each string to a `uint64_t` by shifting left and OR-ing the next bit.
2. To print with leading zeros, loop from `L - 1` down to `0` instead of printing the
   number directly.
3. `__builtin_popcountll(value)` returns the number of set bits.
4. `L` can be `64`, so use an unsigned 64-bit type and the `ULL` suffix.
