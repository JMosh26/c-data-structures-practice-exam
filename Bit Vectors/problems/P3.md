# P3 — Set Duel

| | |
|---|---|
| **Topic** | Bit vectors (set algebra) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

Two sets, `A` and `B`, are given as binary strings of the same length `L`. The leftmost
character describes bit `L - 1` and the rightmost character describes bit `0`. A `1`
means the element is in the set.

Treat each set as a bit vector and report:

- `AND`, `OR`, and `XOR` of the two sets,
- `NOT A`, the complement of `A` **within `L` bits**,
- the number of elements in `A`, in `B`, in their intersection, and in their union,
- whether `A` is a subset of `B`,
- whether the sets are disjoint,
- whether the sets are identical.

## Input Format

- The first line contains one integer, `L`.
- The second line contains two binary strings, `A` and `B`, each exactly `L` characters
  long.

## Output Format

Print exactly eleven lines:

```
AND: bits
OR: bits
XOR: bits
NOT: bits
A: count
B: count
INTERSECTION: count
UNION: count
SUBSET: yes|no
DISJOINT: yes|no
SAME: yes|no
```

Every `bits` value is printed with exactly `L` characters, most significant bit first.
`NOT` is also exactly `L` characters; it is the complement inside the given width, not a
64-bit complement.

Definitions:

- `SUBSET` is `yes` when every element of `A` is also in `B`.
- `DISJOINT` is `yes` when `A` and `B` share no element.
- `SAME` is `yes` when `A` and `B` are identical.

## Constraints

- `1 ≤ L ≤ 64`

## Sample Input 1

```text
8
10110010 11001010
```

## Sample Output 1

```text
AND: 10000010
OR: 11111010
XOR: 01111000
NOT: 01001101
A: 4
B: 4
INTERSECTION: 2
UNION: 6
SUBSET: no
DISJOINT: no
SAME: no
```

## Explanation

`A = 10110010` and `B = 11001010`.

- `AND` keeps only the positions where both have a `1`: `10000010`.
- `OR` has a `1` wherever either set does: `11111010`.
- `XOR` has a `1` where the sets differ: `01111000`.
- `NOT A` flips the 8 bits of `A`: `01001101`.
- Both sets have 4 elements, they share 2, and their union has 6.
- `A` is not a subset of `B`, they are not disjoint, and they are not identical.

## Hints

1. Parse a string by repeatedly shifting left and OR-ing in `1` for `'1'`.
2. Print exactly `L` bits, starting at position `L - 1`.
3. Subset test: `(a & ~b) == 0`.
4. Disjoint test: `(a & b) == 0`.
5. Reuse the same popcount helper for all four counts.
6. `~a` contains high bits beyond `L`; the printer must ignore them.
