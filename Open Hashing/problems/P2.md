# P2 — Reunion Registry

| | |
|---|---|
| **Topic** | Open hashing (separate chaining) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A school reunion keeps a registry of alumni names in `M` buckets using **separate
chaining**. Names are case-sensitive and contain no spaces.

Use this weighted string hash:

```
h(name) = ( sum over i of (i + 1) * ASCII(name[i]) ) mod M
```

where `i` starts at `0` for the first character. New names are **appended at the tail**
of their chain, so each chain stays in insertion order.

Process `Q` commands:

| Command | Meaning |
|---------|---------|
| `ADD name` | Add the name if it is not already registered. Duplicates are silently ignored. |
| `DEL name` | Remove the name from its chain. |
| `FIND name` | Report the bucket and the 1-based position of the name in its chain. |
| `COUNT` | Print how many names are currently registered. |
| `PRINT` | Print every bucket and its chain. |

## Input Format

- The first line contains two integers, `M` and `Q`.
- The next `Q` lines each contain one command, as described above.
- A `name` is a non-empty string of at most 31 characters with no whitespace.

## Output Format

- `ADD` prints nothing.
- `DEL name` prints `REMOVED` if the name was present, otherwise `MISSING`.
- `FIND name` prints `FOUND h p` where `h` is the bucket and `p` is the 1-based chain
  position, or `NOT FOUND`.
- `COUNT` prints the number of registered names.
- `PRINT` prints exactly `M` lines:
  - `i: (empty)` for an empty bucket,
  - `i: name1 -> name2 -> ...` otherwise, in chain order.

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ Q ≤ 10000`
- `1 ≤ length(name) ≤ 31`
- Names are case-sensitive.

## Sample Input 1

```text
5 10
ADD alice
ADD bob
FIND alice
FIND carol
COUNT
PRINT
DEL bob
FIND bob
COUNT
PRINT
```

## Sample Output 1

```text
FOUND 4 1
NOT FOUND
2
0: (empty)
1: (empty)
2: (empty)
3: (empty)
4: alice -> bob
REMOVED
NOT FOUND
1
0: (empty)
1: (empty)
2: (empty)
3: (empty)
4: alice
```

## Explanation

For `alice`, the weighted sum is

```
1*'a' + 2*'l' + 3*'i' + 4*'c' + 5*'e' = 1529
```

and `1529 mod 5 = 4`. For `bob` the sum is `1*'b' + 2*'o' + 3*'b' = 614`, and
`614 mod 5 = 4`. Both names land in bucket 4, so the chain becomes `alice -> bob`.
`alice` is at position 1 and `bob` at position 2. After `DEL bob`, only `alice` remains.

## Hints

1. Accumulate the weighted sum in an `unsigned long long` before taking `% M`.
2. Cast each character to `unsigned char` so non-ASCII bytes cannot become negative.
3. Walk to the tail before appending so insertion order is preserved.
4. To delete from a singly linked list, keep a `Node **` that points at the link you
   may need to change.
5. `FIND` positions start at 1, not 0.
