# P1 — Bucket Brigade

| | |
|---|---|
| **Topic** | Open hashing (separate chaining) |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

You are building the index of a small library. Each book is identified by an integer
key. The index has `M` buckets, and collisions are resolved by **separate chaining**:
each bucket holds a linked list of keys.

Insert `N` keys into the table in the order they are given. Use this hash function:

```
h(k) = ((k mod M) + M) mod M
```

If a key is already present in its chain, ignore the duplicate (do not insert it twice).

After all insertions, print the table from bucket `0` to bucket `M - 1`. Keys inside a
chain must appear in insertion order.

## Input Format

- The first line contains two integers, `M` and `N`.
- The next `N` integers are the keys. They may be spread across one or more lines.

## Output Format

Print exactly `M` lines. For bucket `i`:

- If the bucket is empty: `i: (empty)`
- Otherwise: `i: k1 -> k2 -> ...`

There is one space after the colon, one space on each side of `->`, and no trailing
spaces.

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ N ≤ 10000`
- `-10^9 ≤ key ≤ 10^9`

## Sample Input 1

```text
5 7
12 7 19 5 22 7 3
```

## Sample Output 1

```text
0: 5
1: (empty)
2: 12 -> 7 -> 22
3: 3
4: 19
```

## Explanation

| Key | `key mod 5` | Result |
|-----|-------------|--------|
| 12 | 2 | bucket 2 |
| 7 | 2 | appended to bucket 2 |
| 19 | 4 | bucket 4 |
| 5 | 0 | bucket 0 |
| 22 | 2 | appended to bucket 2 |
| 7 | 2 | duplicate — ignored |
| 3 | 3 | bucket 3 |

## Hints

1. Create an array of `M` node pointers and initialize every entry to `NULL`.
2. `%` can return a negative value for negative keys, so normalize it.
3. Walk to the end of the chain before appending so insertion order is preserved.
4. Free every node before the program ends (good habit, not required by the grader).
