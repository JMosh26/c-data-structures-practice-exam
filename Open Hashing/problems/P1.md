# P1 — Locker Loop

| | |
|---|---|
| **Topic** | Open hashing (separate chaining) |
| **Difficulty** | Easy |
| **Points** | 30 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A school stores its lockers in `M` buckets. Collisions are resolved by **separate
chaining**: every bucket owns a linked list of locker numbers (integer keys).

Insert `N` locker keys into the table in the order they are given. Use this hash
function:

```
h(k) = ((k mod M) + M) mod M
```

This time, each new key is **pushed at the front** of its chain, so the most recently
inserted key becomes the head. If a key is already somewhere in its chain, ignore the
duplicate — do not insert it again and do not move it.

After all insertions, print the table from bucket `0` to bucket `M - 1`, then print
three chain statistics: the number of empty buckets, the number of non-empty buckets,
and the length of the longest chain.

## Input Format

- The first line contains two integers, `M` and `N`.
- The next `N` integers are the keys. They may be spread across one or more lines.

## Output Format

Print exactly `M` lines. For bucket `i`:

- If the bucket is empty: `i: (empty)`
- Otherwise: `i: k1 -> k2 -> ...`

There is one space after the colon, one space on each side of `->`, and no trailing
spaces. After the table, print exactly three more lines:

```
empty: E
chains: C
longest: L
```

`E` is the number of empty buckets, `C` is the number of non-empty buckets, and `L` is
the number of keys in the longest chain (`0` when the table is empty).

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ N ≤ 10000`
- `-10^9 ≤ key ≤ 10^9`

## Sample Input 1

```text
5 7
12 7 19 5 22 7 3
```

## Sample Output 1

```text
0: 5
1: (empty)
2: 22 -> 7 -> 12
3: 3
4: 19
empty: 1
chains: 4
longest: 3
```

## Explanation

| Key | `h(key)` | Chain in bucket 2 after the step |
|-----|----------|----------------------------------|
| 12 | 2 | `12` |
| 7 | 2 | `7 -> 12` |
| 19 | 4 | `7 -> 12` (unchanged) |
| 5 | 0 | `7 -> 12` (unchanged) |
| 22 | 2 | `22 -> 7 -> 12` |
| 7 | 2 | duplicate — ignored |
| 3 | 3 | `22 -> 7 -> 12` (unchanged) |

Bucket `2` therefore prints `2: 22 -> 7 -> 12`. Bucket `1` is the only empty bucket, so
`empty: 1`, `chains: 4`, and the longest chain has 3 keys.

## Hints

1. Create an array of `M` node pointers and initialize every entry to `NULL`.
2. `%` can return a negative value for negative keys, so normalize it.
3. Check for the key with a chain walk **before** inserting, so duplicates are ignored.
4. Head insertion is `node->next = *head; *head = node;`.
5. Free every node before the program ends (good habit, not required by the grader).
