# P3 — Tag Tournament

| | |
|---|---|
| **Topic** | Open hashing (separate chaining) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A social media team is ranking trending tags. Tags are **case-insensitive**, so
`#Cebu`, `#cebu`, and `#CEBU` all count as the same tag. Before hashing or counting,
convert every tag to lowercase.

Use this hash over the normalized tag:

```
h(tag) = ( sum of lowercase ASCII values of tag ) mod M
```

Count how many times each normalized tag appears. Then rank the distinct tags by:

1. **count descending** (more frequent tags first), then
2. **tag ascending** (ordinary lexicographic order) to break ties.

Print the top `K` tags. If there are no tags, or if `K ≤ 0`, print `(none)`.

## Input Format

- The first line contains two integers, `M` and `K`.
- The remaining input contains whitespace-separated tags and ends at end-of-file.
- A tag is a non-empty token of at most 63 characters after normalization.

## Output Format

Print up to `K` lines, each in the form:

```
tag count
```

Tags are already lowercase, separated from the count by one space. Print only
`min(K, number of distinct tags)` lines. If nothing can be printed, print `(none)`.

## Constraints

- `1 ≤ M ≤ 1000`
- `0 ≤ K ≤ 1000`
- `0 ≤ number of tags ≤ 10000`
- Tags contain no whitespace and are at most 127 characters before normalization.

## Sample Input 1

```text
5 3
#Cebu #USC #cebu #Cebu #Manila #USC #Davao
```

## Sample Output 1

```text
#cebu 3
#usc 2
#davao 1
```

## Explanation

After lowercasing, the counts are:

| Tag | Count |
|-----|-------|
| `#cebu` | 3 |
| `#usc` | 2 |
| `#manila` | 1 |
| `#davao` | 1 |

`#manila` and `#davao` tie on count, so the lexicographically smaller tag `#davao`
comes first. With `K = 3`, only the first three tags are printed.

## Hints

1. `tolower` expects an `int` that is either `EOF` or an `unsigned char` value.
2. Hash the normalized tag, not the original token, so case variants share a bucket.
3. When adding a tag, search its chain first; increment the count if found, otherwise
   insert a new node.
4. To rank the tags, collect every node pointer into an array and call `qsort`.
5. A comparator for `Node *` receives `const void *` pointers to `Node *` elements, so
   cast to `Node *const *` before comparing.
6. Remember to cap the output at `min(K, distinct)`.
