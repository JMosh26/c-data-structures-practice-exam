# P3 — Word Watch

| | |
|---|---|
| **Topic** | Open hashing (separate chaining) |
| **Difficulty** | Medium |
| **Points** | 35 |
| **Time limit** | 1.0 s |
| **Memory limit** | 64 MB |

## Description

A writing center wants to know how often each word appears in a document. Implement a
word-frequency table with **separate chaining**.

- Convert every word to lowercase before processing it. `Hello`, `hello`, and `HELLO`
  are the same word and must be counted together.
- Hash a word with the sum of the ASCII values of its lowercase characters:

```
h(word) = (sum of ASCII values) mod M
```

- The first time a word appears, append it to the end of its bucket's chain.
- Every later appearance increments that word's count. Do not create a second node and
  do not change the node's position in the chain.

After reading every word, print the buckets from `0` to `M - 1`.

## Input Format

- The first line contains the integer `M`.
- The rest of the input contains words separated by whitespace. Read until **end of
  file**; the words are not necessarily on a single line.

A word contains only letters and digits. Its length is at most `31` characters after
lowercasing.

## Output Format

Print exactly `M` lines. For bucket `i`:

- Empty: `i: (empty)`
- Otherwise: `i: word1:count1 -> word2:count2 -> ...`

Chains are printed in first-appearance order. There is one space after the colon, one
space on each side of `->`, and no trailing spaces.

## Constraints

- `1 ≤ M ≤ 100`
- `1 ≤ number of words ≤ 1000`
- `1 ≤ length of a word ≤ 31`

## Sample Input 1

```text
5
the cat the dog the cat bird
```

## Sample Output 1

```text
0: (empty)
1: the:3
2: cat:2 -> bird:1
3: (empty)
4: dog:1
```

## Explanation

| Word | ASCII sum | Bucket | Count |
|------|-----------|--------|-------|
| the | 116 + 104 + 101 = 321 | 1 | 3 |
| cat | 99 + 97 + 116 = 312 | 2 | 2 |
| dog | 100 + 111 + 103 = 314 | 4 | 1 |
| bird | 98 + 105 + 114 + 100 = 417 | 2 | 1 |

`cat` enters bucket `2` before `bird`, so it is printed first even though both are in
the same chain.

## Hints

1. Read tokens with `scanf("%s", ...)` until it returns `EOF`.
2. Lowercase each character with `tolower` from `<ctype.h>`.
3. Search the chain before inserting. If found, increment `count`.
4. Keep the tail of each chain (or walk to the end) so new words are appended, not
   prepended.
